# last30days

Research what people actually say about any topic in the last 30 days. Pulls posts and engagement from Reddit, X, YouTube, TikTok, Hacker News, Polymarket, GitHub, and the web.

> **Transparency**
>
> This is Silicon Valley Academy's modified version of [last30days-skill](https://github.com/mvanhorn/last30days-skill) by mvanhorn, published under the original MIT license.

## Install

Paste this into Claude Code:

```
Install the last30days skill from github.com/sva-admin/last30days
```

## Use it

```
/last30days nvidia earnings reaction
/last30days AI video tools
/last30days what users want in react
```

Every source is optional. The skill works with no API keys at all and gets deeper as you add them. See `SKILL.md` for the full list of optional providers.
